How to put webpages buttons on top like this ↑

  1. Put the buttons in the div element
  2. Then put them in a flexbox, "display: flex;"
  3. Then sort them horizontally, by putting equal space in between them, "justify-content: space-between;"

How to put the up against the wall like this
←

  1. First nest your buttons or links in div, but also put class on your buttons
  2. Then put them in a flexbox, "display: flex;"
  3. Then sort it vertically, "flex-direction: column;"
  4. Probably put some gap too, "gap: (your amount)rem (or px)
  5. Then using the class, change the appearances of your buttons

And also how to put text next to the buttons against the wall

  1. Put that element and set of buttons in same element
  2. Then take that div, and place the display code, "display: inline-block;"
