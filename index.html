How to work with canvas from HTML:

<canvas id="gameCanvas" width="800" height="600"></canvas> = height would be 150px, and width would be 300px if you don't specify it in your canvas.


Then switch to Javascript:

const canvas = document.getElementById("gameCanvas");
const ctx = canvas.getContext("2d");

// Draw a rectangle
ctx.fillStyle = "blue";
ctx.fillRect(80, 60, 150, 100);

// Draw a circle
ctx.arc(200, 150, 50, 0, Math.PI * 2, false);
ctx.fillStyle = "red";
ctx.fill()

// Draw a triangle
ctx.save();
ctx.translate(-80, -30)
ctx.beginPath();
ctx.moveTo(150, 70);
ctx.lineTo(80, 140);
ctx.lineTo(220, 140);
ctx.closePath();
ctx.fillStyle = 'green';
ctx.fill();
ctx.restore();

// Add text
ctx.fillStyle = "black";
ctx.font = "20px Arial";
ctx.fillText("Hello, Canvas!", 120, 50);
